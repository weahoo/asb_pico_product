Connection path

Before you start

A StackHub, an ASB/MCP host computer with desktop Chrome, Edge or Chromium, a USB data cable, a 2.4 GHz uplink with internet access, and a Chan/Xiaozhi MCP WSS endpoint. StackHub uses the uplink for WSS; the computer browser accesses the backend.

Compatibility & limits

The computer browser, not the board, calls the backend. Local 127.0.0.1 refers to that computer. A local ASB backend does not require the computer to join the hub hotspot; a remote backend must be reachable from the computer and allow browser CORS. No stdio process launching, OAuth login, legacy SSE or multi-backend aggregation. One request at a time; large results are limited by firmware. Use search → schema → call instead of exporting the entire catalog. Category availability depends on the installed firmware and backend. Keep real tokens private. Chan end-to-end compatibility must be checked with the installed firmware.

Subscription testing is available for $6/month in Creem test mode. No real charges are made. Hardware purchase inquiries remain separate.
