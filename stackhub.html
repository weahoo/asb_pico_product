Bring AI to offline computers.

Across security boundaries. Across AI platforms. On your terms.

StackHub is an independently connected USB AI hardware bridge. Your target computer needs no direct internet, Wi‑Fi or Ethernet connection to use authorized AI tool capabilities through a local desktop Bridge.

USE CASES

What can you do with StackHub?

01

AI tools on offline computers

The target computer stays off the internet. Authorized AI reaches only configured MCP tools through the StackHub bridge.

02

Work with your local information

Choose the local tools, folders and workflows you want to share with AI, keeping access in your hands.

03

Work memory and automation

Look up project notes and decisions saved in Memory MCP, or call authorized local tools and ASB workflows.

04

StackChan desktop robots

Switch compatible hardware into StackChan mode to connect a desktop robot to its AI/MCP workflow.

SETUP

Three steps to get started

External AI / MCP→StackHub · Wi-Fi →USB Bridge→Offline PC / MCP
  1. 01Configure StackHub's own Wi‑Fi and connect it to the target computer by USB.
  2. 02Open local desktop Bridge, bind the device and install Memory MCP or configure existing tools.
  3. 03Use compatible AI to call authorized tools, or switch to StackChan mode.

STACKHUB / CONTROLLED AI BRIDGE

让离线电脑，也能获得 AI 能力。

纵向连接受限环境，横向连接不同 AI。访问边界由你决定。

StackHub 是独立联网的 USB AI 硬件桥梁。目标电脑无需连接互联网、Wi‑Fi 或以太网，即可通过本地 Bridge 使用获授权的 AI 工具能力。

离线目标电脑按需开放 MCP 工具跨 AI 与桌面机器人
查看软件套餐咨询购买 StackHub 硬件安装使用指南
01 / VERTICAL

纵向 · 让 AI 进入受限环境

实验室、办公室、车间等场景中，即使电脑不直接连接互联网，也能通过 StackHub 的独立 Wi-Fi 与 USB Bridge 使用选定的 AI 工具。

02 / HORIZONTAL

横向 · 一套桥接，多种 AI

一个 StackHub，连接多种支持 MCP 的 AI 和兼容的 StackChan 桌面机器人；Windows、macOS 和 Linux 都可通过桌面 Bridge 接入。

Claude · MCP AI · StackChan · Windows · macOS · Linux

USE CASES

你可以拿 StackHub 做什么？

01

隔离电脑上的 AI 能力

目标电脑不接互联网。AI 通过 StackHub 访问事先配置、获授权的 MCP 工具，省去为电脑开放外网的需求。

02

按需连接工作资料

选择需要开放的本地工具、文件夹和工作流程，让 AI 在你的许可下获取需要的信息并协助完成工作。

03

工作记忆与自动化

让 AI 查找 Memory MCP 已保存的项目笔记、决策和背景；按需调用授权的本地工具及 ASB 流程。

04

StackChan 桌面机器人

在兼容设备上切换到 StackChan 模式，连接桌面机器人对应的 AI/MCP 工作流。

SETUP

只需三步

External AI / MCP→StackHub · Wi-Fi →USB Bridge→Offline PC / MCP
  1. 01配置 StackHub 自身的 Wi‑Fi 并连接电脑 USB。
  2. 02启动本地桌面 Bridge，绑定设备，安装 Memory MCP 或配置已有工具。
  3. 03用支持 MCP 的 AI 调用授权工具；或切换兼容 StackChan 模式。

Apple Shortcuts / Siri — Coming Soon — 未来计划支持通过 Siri 和 Apple 快捷指令发起 AI 工作流程，敬请期待。
