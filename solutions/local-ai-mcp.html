本地大模型如何使用 MCP 工具？

支持 MCP 的模型客户端可以通过 StackHub 访问已配置的工具服务。

如何使用

先确认客户端支持所需 MCP 连接方式，再按指南配置和验证工具调用。

查看完整操作指南

适用条件与限制

模型本身不等于 MCP 客户端；兼容性、权限和网络条件需逐项确认。

常见问题

所有 Ollama 模型都能直接调用吗？

不能保证，需要支持 MCP 和工具调用的客户端及适配模型。
