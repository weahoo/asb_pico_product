这台设备已连接 FlexHub-Transfer 热点。登录后可发送到电脑，也可领取电脑文件并下载。

进入传输页面

USB 电脑：发送 / 接收

在 USB 连接 Transfer Hub 的电脑上，用 Chrome / Edge 打开接收页，授权 USB 后选择发送或接收；接收时再选择保存文件夹。

下载离线接收页打开在线接收页
离线使用：电脑先连接此热点下载接收页，打开下载的 HTML 后即可使用 USB 双向传输，无需互联网。
浏览器限制：此热点的 HTTP 页面和自动弹出的登录窗口不能直接连接 USB。

在线接收页需要互联网，或之前已缓存。USB 单独插入电脑不会自动打开网页。此入口适用于专用文件传输固件。

弹出窗口无法选择文件时，请用普通浏览器打开 192.168.77.1。
