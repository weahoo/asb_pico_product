Before you start

Prepare your StackHub, a USB data cable, a Windows, macOS or Linux computer with a desktop browser, and a 2.4 GHz Wi-Fi network. StackHub Bridge manages the device and its local tools.

Step by step

  1. Power on StackHub. Connect your phone to the stackhub hotspot, open http://192.168.78.1/ in a browser and sign in with the device password.
  2. Connect StackHub to your 2.4 GHz Wi-Fi network and activate your device. Save the 24-character recovery code for future use.
  3. Use your recovery code to retrieve your device-specific WSS and MCP connection details, then follow the device page to complete WSS setup.
  4. Open StackHub Bridge on your computer, connect the device by USB and select it. Add Memory MCP with one click or configure your preferred MCP tools.
  5. In your MCP-compatible AI client, paste the complete MCP URL, or use the standard JSON + Header configuration provided in your email.
  6. Find and call StackHub tools in your AI client to start working with local tools and saved work memory.

Connect your AI client

Your email includes two ways to connect: paste the full MCP URL, or use the standard MCP JSON with an Authorization: Bearer header. Choose whichever your AI client supports.

If StackHub performs poorly with one AI, first try another MCP-compatible AI client. Tool-call behavior may vary between AI services.

Helpful tips

StackHub uses its own Wi-Fi to reach AI services while the target computer stays offline. Keep your MCP URL and recovery code safe. When moving to another computer, follow the Bridge pairing steps again.

开始前准备

准备 StackHub、USB 数据线、带有桌面浏览器的 Windows、macOS 或 Linux 电脑，以及可用的 2.4 GHz Wi-Fi。连接和工具管理通过 StackHub Bridge 完成。

操作步骤

  1. 接通 StackHub 电源。用手机连接 stackhub 热点，在浏览器打开 http://192.168.78.1/，输入设备管理密码。
  2. 按照管理页提示连接 2.4 GHz Wi-Fi 并激活设备，妥善保存你的 24 位恢复码。
  3. 使用恢复码获取设备专属 WSS 与 MCP 连接信息，并按设备管理页指引完成 WSS 配置。
  4. 在电脑上启动 StackHub Bridge，使用 USB 连接 StackHub，按提示选择设备。可一键添加 Memory MCP，或配置你常用的 MCP 工具。
  5. 在支持 MCP 的 AI 客户端粘贴完整 MCP URL；也可使用邮件提供的标准 JSON + Header 配置，任选一种即可。
  6. 在 AI 中搜索 StackHub 工具并尝试调用，开始使用你的本地工具和工作记忆。

连接 AI 客户端

邮件提供两种连接方法：直接使用完整 MCP URL，或使用包含 Authorization: Bearer Header 的标准 MCP JSON。选择你的 AI 客户端支持的方式即可。

如果某个 AI 调用 StackHub 时表现不佳，建议优先切换到另一款支持 MCP 的 AI 再试；不同 AI 客户端的工具调用行为可能不同。

準備するもの

StackHub、USBデータケーブル、Windows・macOS・LinuxのPC、2.4 GHz Wi-Fiを用意します。デバイスとローカルツールはStackHub Bridgeで管理します。

操作手順

  1. StackHubの電源を入れ、スマホをstackhubのWi-Fiに接続します。ブラウザーで http://192.168.78.1/ を開き、管理パスワードでログインします。
  2. 2.4 GHz Wi-Fiを設定してデバイスを有効化し、発行された24文字のリカバリーコードを保存します。
  3. リカバリーコードでデバイス専用WSSとMCPの接続情報を取得し、管理画面の案内に沿ってWSSを設定します。
  4. PCでStackHub Bridgeを開き、USBで接続してデバイスを選択します。Memory MCPをワンクリックで追加するか、お好みのMCPツールを設定します。
  5. AIクライアントにはメール記載の完全なMCP URL、またはHeader付きの標準JSONを入力します。
  6. AIからStackHubのツールを検索・実行して使い始めます。

AIクライアントの接続

メールには完全なMCP URLと、Authorization: Bearer Headerを含む標準MCP JSONの2つが用意されています。対応する方式を選択してください。

あるAIでStackHubの動作が不安定な場合は、まず別のMCP対応AIでお試しください。AIごとにツールの呼び出し動作が異なる場合があります。

Vorbereitung

Sie benötigen StackHub, ein USB-Datenkabel, einen Windows-, macOS- oder Linux-Computer mit Browser sowie ein 2,4-GHz-WLAN. Geräte und Tools verwalten Sie über StackHub Bridge.

Schritt für Schritt

  1. StackHub einschalten. Das Smartphone mit dem WLAN stackhub verbinden, http://192.168.78.1/ öffnen und mit dem Gerätepasswort anmelden.
  2. Das 2,4-GHz-WLAN einrichten, das Gerät aktivieren und den 24-stelligen Wiederherstellungscode sicher aufbewahren.
  3. Mit dem Wiederherstellungscode die WSS- und MCP-Verbindungsdaten abrufen und WSS nach Anleitung im Geräteportal einrichten.
  4. StackHub Bridge auf dem Computer starten, das Gerät per USB verbinden und auswählen. Memory MCP per Klick hinzufügen oder weitere MCP-Tools einrichten.
  5. Im MCP-kompatiblen KI-Client die vollständige MCP-URL oder die Standard-JSON-Konfiguration mit Header aus der E-Mail einfügen.
  6. Im KI-Client StackHub-Tools suchen und aufrufen, um loszulegen.

KI-Client verbinden

Die E-Mail bietet zwei Optionen: die vollständige MCP-URL oder Standard-MCP-JSON mit Authorization: Bearer Header. Wählen Sie die von Ihrem KI-Client unterstützte Variante.

Wenn StackHub mit einer KI unzuverlässig arbeitet, probieren Sie zuerst einen anderen MCP-kompatiblen KI-Client. Das Verhalten bei Tool-Aufrufen kann variieren.

Tipps zur Verwendung

Préparation

Prévoyez StackHub, un câble USB, un PC Windows, macOS ou Linux avec navigateur, et un réseau Wi-Fi 2,4 GHz. Le matériel et les outils locaux se gèrent dans StackHub Bridge.

Étapes

  1. Allumez StackHub, connectez le téléphone au Wi-Fi stackhub, ouvrez http://192.168.78.1/ et connectez-vous avec le mot de passe de l’appareil.
  2. Configurez le Wi-Fi 2,4 GHz, activez l’appareil et conservez votre code de récupération de 24 caractères.
  3. À l’aide du code, récupérez vos informations de connexion WSS et MCP et suivez les indications de la page de gestion pour configurer WSS.
  4. Ouvrez StackHub Bridge sur le PC, branchez StackHub en USB et choisissez l’appareil. Ajoutez Memory MCP en un clic ou configurez vos outils MCP.
  5. Dans votre client IA compatible MCP, collez l’URL MCP complète ou la configuration JSON + Header envoyée par e-mail.
  6. Recherchez et utilisez vos outils StackHub depuis le client IA.

Connecter votre client IA

Votre e-mail contient deux options : l’URL MCP complète ou le JSON MCP standard avec un en-tête Authorization: Bearer. Choisissez celle compatible avec votre client.

Si StackHub fonctionne mal avec une IA, essayez d’abord un autre client IA compatible MCP. Le comportement des appels d’outils peut varier.

Télécharger StackHub Bridge

Paquets hors ligne complets pour Windows et Linux x86_64 (candidats RC4) avec Node.js portable et Memory MCP.

Windows · ZIP hors ligneLinux · TAR.GZ hors ligne

Versions de test non signées. Le paquet Windows inclut l’EXE RC4 identique à celui validé sur le matériel réel et l’outil de flash BL616 hors ligne. Sauvegardez le dossier et conservez managed-mcp pour préserver Memory et la configuration. Le domaine R2 public de développement est limité en débit.

Conseils pratiques

StackHub utilise son propre Wi-Fi pour les services IA tandis que le PC cible reste hors ligne. Conservez soigneusement votre URL MCP et votre code de récupération.

자세히모든 제품

준비

StackHub, USB 데이터 케이블, 브라우저가 있는 Windows·macOS·Linux PC, 2.4 GHz Wi-Fi를 준비하세요. 장치와 로컬 도구는 StackHub Bridge로 관리합니다.

사용 순서

  1. StackHub 전원을 켜고 휴대폰을 stackhub Wi-Fi에 연결합니다. 브라우저에서 http://192.168.78.1/을 열고 기기 암호로 로그인하세요.
  2. 2.4 GHz Wi-Fi를 설정하고 기기를 활성화한 다음 24자리 복구 코드를 안전하게 저장하세요.
  3. 복구 코드로 전용 WSS와 MCP 연결 정보를 확인하고 기기 관리 화면의 안내에 따라 WSS를 설정하세요.
  4. PC에서 StackHub Bridge를 실행하고 USB로 연결한 뒤 장치를 선택합니다. Memory MCP를 한 번에 추가하거나 사용할 MCP 도구를 설정하세요.
  5. MCP 지원 AI 클라이언트에 이메일의 전체 MCP URL 또는 Header가 포함된 표준 JSON을 입력하세요.
  6. AI에서 StackHub 도구를 검색하고 호출하여 사용을 시작하세요.

AI 클라이언트 연결

이메일에는 전체 MCP URL과 Authorization: Bearer Header가 포함된 표준 MCP JSON 두 가지 방법이 있습니다. 지원되는 방식을 선택하세요.

특정 AI에서 StackHub 동작이 원활하지 않다면 먼저 다른 MCP 호환 AI에서 시도해 보세요. AI마다 도구 호출 동작이 다를 수 있습니다.

StackHub Bridge 다운로드

휴대용 Node.js와 기본 Memory MCP가 포함된 Windows 및 Linux x86_64 오프라인 전체 패키지(RC4 개발 후보)입니다.

Windows · 오프라인 ZIPLinux · 오프라인 TAR.GZ

서명되지 않은 시험용 빌드입니다. Windows 패키지에는 실제 장치에서 검증한 RC4 EXE와 BL616 오프라인 플래시 도구가 그대로 포함됩니다. 업데이트 전에 폴더를 백업하고 Memory와 설정을 유지하려면 managed-mcp를 보존하세요. 공개 R2 개발 도메인에는 요청 제한이 있습니다.

사용 팁

StackHub는 독립 Wi-Fi로 AI 서비스에 연결되며 대상 PC는 오프라인을 유지할 수 있습니다. MCP URL과 복구 코드를 안전하게 보관하세요.

التحضير

جهّز StackHub وكابل USB وحاسوب Windows أو macOS أو Linux بمتصفح وشبكة Wi-Fi بتردد 2.4 GHz. تُدار الأدوات المحلية من خلال StackHub Bridge.

خطوات الاستخدام

  1. شغّل StackHub ووصل الهاتف بشبكة stackhub، ثم افتح http://192.168.78.1/ في المتصفح وسجّل الدخول بكلمة مرور الجهاز.
  2. اضبط شبكة Wi-Fi بتردد 2.4 GHz وفعّل الجهاز، ثم احتفظ برمز الاستعادة المكوّن من 24 حرفاً.
  3. استخدم رمز الاستعادة للحصول على بيانات WSS وMCP الخاصة بجهازك، واتبع صفحة الإدارة لإعداد WSS.
  4. افتح StackHub Bridge على الحاسوب، وصِل الجهاز عبر USB واختره. أضف Memory MCP بنقرة واحدة أو اضبط أدوات MCP التي تفضّلها.
  5. في تطبيق الذكاء الاصطناعي المتوافق مع MCP، ألصق عنوان MCP الكامل أو إعداد JSON مع Header الوارد في البريد.
  6. ابحث عن أدوات StackHub في تطبيق الذكاء الاصطناعي وابدأ استخدامها.

توصيل تطبيق الذكاء الاصطناعي

تتضمن الرسالة خيارين: عنوان MCP الكامل، أو إعداد MCP JSON القياسي مع ترويسة Authorization: Bearer. اختر الطريقة التي يدعمها تطبيقك.

إذا لم يعمل StackHub جيداً مع أحد تطبيقات الذكاء الاصطناعي، فجرّب أولاً تطبيقاً آخر يدعم MCP، فقد تختلف طريقة استدعاء الأدوات بين التطبيقات.
