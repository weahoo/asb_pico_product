Connection path

Before you start

A TransferHub, a USB data cable, a computer with desktop Chrome or Edge, and a phone/tablet with Wi-Fi and a browser. A compatible Chromium browser on Windows, macOS or Linux needs Web Serial and file-saving support. iPhone/iPad can use the Wi-Fi side; USB browser hosting on them is not supported.

Compatibility & limits

Dedicated transfer firmware is required. Reverse transfer requires protocol v2 firmware on Pico or BL616. One file and one direction at a time. Updated firmware and receiver pages support Wi-Fi interruption recovery for up to 10 minutes while USB and the computer page remain open. Phone uploads can resume with the same file; reverse downloads use browser HTTP Range resume where supported. Reboot or USB disconnection requires restarting. The configured limit is 4 GiB, not a verified maximum-size transfer. Files are streamed in bounded chunks, not stored whole on the hub. USB must use the HTTPS site or offline page, not the hotspot HTTP page. No internet is needed after downloading the offline package. If Linux cannot open the port, check serial-device permissions. Software tests do not establish board throughput.
