Before you start

A TransferHub, a USB data cable, a computer with desktop Chrome or Edge, and a phone/tablet with Wi-Fi and a browser. A compatible Chromium browser on Windows, macOS or Linux needs Web Serial and file-saving support. iPhone/iPad can use the Wi-Fi side; USB browser hosting on them is not supported.

Step by step

  1. Connect TransferHub to the computer with a USB data cable. Open the online transfer page, or download and extract the offline ZIP in advance, then open FlexHub-Receiver.html.
  2. On the computer, click Connect USB, choose the device and log in with its configured password. The computer does not need to join the hotspot.
  3. On the phone, join FlexHub-Transfer and open http://192.168.77.1/ in a normal browser. Log in with the device credentials; use the supplied password if it has not been changed.
  4. Phone → computer: choose Receive on the USB page and grant a destination folder. Choose Send on the phone, select a file and start.
  5. Computer → phone: choose Send on the USB page and offer a file. Choose Receive on the phone and Download. Check the phone’s download list to confirm saving.
  6. Keep both pages open and devices awake. Cancel an interrupted transfer and start again. For offline use, keep the extracted files together.
Open transfer pageDownload offline ZIP

Compatibility & limits

Dedicated transfer firmware is required. Reverse transfer requires protocol v2 firmware on Pico or BL616. One file and one direction at a time; no resume. The configured limit is 4 GiB, not a verified maximum-size transfer. Files are streamed in bounded chunks, not stored whole on the hub. USB must use the HTTPS site or offline page, not the hotspot HTTP page. No internet is needed after downloading the offline package. If Linux cannot open the port, check serial-device permissions. Software tests do not establish board throughput.

开始前准备

准备 TransferHub、USB 数据线、安装桌面 Chrome 或 Edge 的电脑，以及带 Wi-Fi 和浏览器的手机／平板。Windows、macOS、Linux 的 Chromium 浏览器需支持 Web Serial 和文件保存能力。iPhone／iPad 可作为 Wi-Fi 侧；不支持在其浏览器中充当 USB 宿主。

操作步骤

  1. 用 USB 数据线连接 TransferHub 和电脑。在电脑打开在线传输网页；或事先下载并完整解压离线 ZIP，打开 FlexHub-Receiver.html。
  2. 电脑网页点击连接 USB，选择设备并用设备已设置的密码登录。电脑不需要连接 Hub 热点。
  3. 手机连接 FlexHub-Transfer 热点，用普通浏览器打开 http://192.168.77.1/ 并登录。密码以设备随附信息或你修改后的设置为准。
  4. 手机 → 电脑：USB 网页选择“接收”并授权目标文件夹；手机选择“发送”，选文件后开始。
  5. 电脑 → 手机：USB 网页选择“发送”并选择文件；手机选择“接收”与“下载”。最后在手机浏览器下载列表确认文件保存成功。
  6. 传输期间保持两边网页打开、设备唤醒。中断后取消并重新开始。离线使用时保留完整解压目录；若弹出的热点小窗口无法下载，请改用正常浏览器。

兼容性与限制

必须烧录专用传输固件；反向传输需要 Pico／BL616 的协议 v2 固件。一次一个文件、一个方向，不支持断点续传。配置上限为 4 GiB，并非已实测的最大文件。Hub 只缓冲小块数据，不完整存储文件。USB 侧使用 HTTPS 网站或离线网页，不能直接使用热点 HTTP 网页访问 USB。提前下载离线包后无需互联网。Linux 若打不开串口，请检查串口设备权限。软件测试不代表已验证实际板端速度。

準備するもの

TransferHub、USB データケーブル、デスクトップ Chrome/Edge のパソコン、Wi-Fi とブラウザーのあるスマホを用意。Windows/macOS/Linux は Web Serial とファイル保存に対応するブラウザーが必要です。iPhone/iPad は Wi-Fi 側のみ対応。

操作手順

  1. USB でパソコンに接続。オンライン転送ページ、または事前にダウンロード・展開した ZIP の FlexHub-Receiver.html を開きます。
  2. Connect USB で機器を選び、設定済みパスワードでログイン。パソコンのホットスポット接続は不要です。
  3. スマホを FlexHub-Transfer に接続し、通常のブラウザーで http://192.168.77.1/ を開いてログイン。パスワードは製品案内または変更後のものを使います。
  4. スマホ→パソコン：USB 側は Receive と保存フォルダー、スマホ側は Send とファイルを選択。
  5. パソコン→スマホ：USB 側は Send とファイル、スマホ側は Receive、Download。ダウンロード一覧で保存を確認。
  6. 両方のページを開き、端末を起動状態に保ちます。中断時はキャンセルして再送。小さい接続画面で保存できなければ通常のブラウザーを使います。
転送ページを開くオフライン ZIP

互換性と制限

逆方向はプロトコル v2 固件が必要。1回1ファイル・1方向、再開機能なし。設定上限4 GiBは実機検証済みサイズではありません。Hubは小分けに中継し、ファイル全体を保存しません。USB側はHTTPSかオフラインページを使用。事前取得後はネット不要。Linuxはシリアルポート権限を確認。速度は実機ごとに確認が必要です。

Vorbereitung

TransferHub, USB-Datenkabel, Computer mit Desktop-Chrome/Edge und Smartphone mit WLAN/Browser. Windows/macOS/Linux benötigen Web Serial und Dateispeicherung im Browser. iPhone/iPad nur auf der WLAN-Seite.

Schritt für Schritt

  1. Hub per USB anschließen. Online-Transferseite oder die vorab entpackte FlexHub-Receiver.html öffnen.
  2. Connect USB wählen, Gerät auswählen und mit dem Gerätepasswort anmelden. Der Computer braucht keine Hotspot-Verbindung.
  3. Telefon mit FlexHub-Transfer verbinden, http://192.168.77.1/ im normalen Browser öffnen und anmelden. Das mitgelieferte oder geänderte Passwort verwenden.
  4. Telefon → Computer: USB-Seite Receive, Zielordner freigeben; Telefon Send, Datei auswählen.
  5. Computer → Telefon: USB-Seite Send und Datei; Telefon Receive und Download. Speicherung in der Downloadliste prüfen.
  6. Beide Seiten offen und Geräte wach halten. Nach Abbruch neu starten; keine Fortsetzung. Für Offline-Nutzung alle entpackten Dateien zusammenlassen.
Transferseite öffnenOffline-ZIP herunterladen

Kompatibilität und Grenzen

Rückrichtung benötigt Protokoll-v2-Firmware. Eine Datei und Richtung gleichzeitig. 4 GiB ist die konfigurierte, nicht physisch getestete Grenze. Nur kleine Blöcke werden gepuffert. USB über HTTPS oder Offline-Seite, nicht über die HTTP-Hotspotseite. Nach Download kein Internet nötig. Unter Linux serielle Zugriffsrechte prüfen. Durchsatz hängt vom Gerät ab.

Préparation

TransferHub, câble USB de données, ordinateur avec Chrome/Edge et téléphone Wi-Fi. Sous Windows/macOS/Linux, le navigateur doit gérer Web Serial et l’enregistrement des fichiers. iPhone/iPad : côté Wi-Fi uniquement.

Étapes

  1. Branchez le hub au PC. Ouvrez la page en ligne ou FlexHub-Receiver.html après téléchargement et extraction du ZIP.
  2. Connect USB : sélectionnez le hub et entrez son mot de passe. Le PC n’a pas besoin de rejoindre le point d’accès.
  3. Connectez le téléphone à FlexHub-Transfer, ouvrez http://192.168.77.1/ dans un navigateur normal et identifiez-vous avec le mot de passe fourni ou modifié.
  4. Téléphone → PC : Receive sur USB, autorisez un dossier ; Send et choisissez un fichier sur le téléphone.
  5. PC → téléphone : Send et sélectionnez un fichier sur USB ; Receive puis Download sur le téléphone. Vérifiez la liste des téléchargements.
  6. Gardez les deux pages ouvertes et les appareils éveillés. Annulez et recommencez après interruption. Conservez tous les fichiers du ZIP extrait.

Compatibilité et limites

Le sens inverse nécessite le firmware protocole v2. Un fichier et un sens à la fois, sans reprise. La limite configurée de 4 GiB n’est pas validée sur matériel. Le hub ne conserve que de petits blocs. USB via HTTPS ou page hors ligne, pas via la page HTTP du point d’accès. Internet inutile après téléchargement. Sous Linux, vérifier les permissions du port série. Débit matériel à vérifier.

자세히모든 제품

준비

TransferHub, USB 데이터 케이블, 데스크톱 Chrome/Edge 컴퓨터, Wi-Fi 휴대폰이 필요합니다. Windows/macOS/Linux 브라우저는 Web Serial과 파일 저장을 지원해야 합니다. iPhone/iPad는 Wi-Fi 쪽만 지원합니다.

사용 순서

  1. USB로 연결하고 온라인 전송 페이지 또는 미리 다운로드·압축 해제한 FlexHub-Receiver.html을 엽니다.
  2. Connect USB에서 장치를 선택하고 설정된 암호로 로그인합니다. 컴퓨터는 핫스팟에 연결할 필요가 없습니다.
  3. 휴대폰을 FlexHub-Transfer에 연결하고 일반 브라우저에서 http://192.168.77.1/을 열어 로그인합니다. 제공된 암호 또는 변경한 암호를 사용합니다.
  4. 휴대폰→컴퓨터: USB 페이지는 Receive와 저장 폴더, 휴대폰은 Send와 파일을 선택합니다.
  5. 컴퓨터→휴대폰: USB 페이지는 Send와 파일, 휴대폰은 Receive와 Download를 선택합니다. 다운로드 목록에서 저장을 확인합니다.
  6. 두 페이지를 열어 두고 절전 상태를 피하세요. 중단하면 취소 후 다시 시작하세요. 오프라인 파일은 함께 보관하세요.
전송 페이지 열기오프라인 ZIP 다운로드

호환성과 제한

역방향은 프로토콜 v2 펌웨어가 필요합니다. 한 번에 한 파일·한 방향, 이어받기 없음. 설정 한도 4 GiB는 실기 검증 한도가 아닙니다. 작은 블록만 버퍼링합니다. USB는 HTTPS 또는 오프라인 페이지를 사용하며 핫스팟 HTTP 페이지는 사용할 수 없습니다. 다운로드 후 인터넷은 불필요합니다. Linux는 직렬 포트 권한을 확인하세요. 속도는 실기 확인이 필요합니다.

التحضير

تحتاج TransferHub وكابل بيانات USB وحاسوب Chrome/Edge وهاتف Wi-Fi. يلزم دعم Web Serial وحفظ الملفات على Windows/macOS/Linux. يعمل iPhone/iPad على جانب Wi-Fi فقط.

خطوات الاستخدام

  1. صِل الجهاز بالحاسوب وافتح صفحة النقل، أو نزّل ZIP مسبقاً وفكّه ثم افتح FlexHub-Receiver.html.
  2. اختر Connect USB والجهاز، ثم سجّل الدخول بكلمة مروره. لا يحتاج الحاسوب إلى شبكة نقطة الاتصال.
  3. صِل الهاتف بشبكة FlexHub-Transfer وافتح http://192.168.77.1/ في متصفح عادي وسجّل الدخول بالكلمة المرفقة أو المعدلة.
  4. الهاتف إلى الحاسوب: اختر Receive ومجلد الحفظ على USB، ثم Send والملف على الهاتف.
  5. الحاسوب إلى الهاتف: اختر Send والملف على USB، ثم Receive وDownload على الهاتف. تأكد من الحفظ في قائمة التنزيلات.
  6. أبقِ الصفحتين مفتوحتين والأجهزة مستيقظة. ألغِ النقل المتوقف وابدأ من جديد. احتفظ بكل ملفات الحزمة معاً.

التوافق والحدود

يتطلب الاتجاه العكسي البرنامج الثابت ببروتوكول v2. ملف واتجاه واحد في كل مرة، دون استئناف. حد 4 GiB مُعدّ ولم يُثبت باختبار مادي بهذا الحجم. تُخزّن أجزاء صغيرة مؤقتاً فقط. استخدم HTTPS أو الصفحة دون اتصال لـUSB، وليس صفحة HTTP الخاصة بالنقطة. لا يلزم الإنترنت بعد التنزيل. تحقق من أذونات المنفذ التسلسلي في Linux. السرعة تحتاج اختبار الجهاز.
