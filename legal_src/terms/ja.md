## 1. 製品とサービス
StackHub、FlexHub、TransferHub は機能の異なるハードウェアです。購入前に製品ページとガイドで機能、互換性、動作条件をご確認ください。StackHub には別料金のソフトウェアプラン、機器の有効化・接続サービスがあります。ハードウェア価格に有料 AI サブスクリプションや外部 API の料金は原則含まれません。

お支払い前に製品ページまたは決済画面で価格、通貨、税金、送料、継続課金を確認してください。購入内容と最終金額は決済時の確認内容に従います。明示がなければ在庫あり・予約販売と推測しないでください。価格、配送条件、必要な販売事業者情報が不明な場合は注文前にご連絡ください。
## 3. 決済とサブスクリプション
決済手段と決済事業者は購入画面に表示されます。StackHub の契約期間、更新、利用上限、解約条件は申込前に確認し、購入時の表示内容に従います。外部 AI の契約、利用料、持込 API キー（BYOK）は原則お客様の負担です。
## 4. 設定、データ、更新
付属の手順に従ってください。StackHub はオンラインゲートウェイと MCP により AI や PC のローカルツールに接続できます。FlexHub は入力操作、TransferHub は互換機器間のファイル転送を行います。リカバリーコード、WSS URL、パスワード、キーを保護し、更新・初期化・交換前にデータをバックアップしてください。対応状況は OS や外部サービスによって異なります。ファームウェア等の更新とオープンソースライセンスには各条件が適用されます。
## 5. 安全と利用範囲
所有または正当に利用を許可された機器・サービスだけを操作してください。不正アクセス、有害な自動化、マルウェアや安全上重要な制御に使用しないでください。無線通信には遅延や切断があり得ます。重要な操作を確認し、バックアップと電源・USB の安全対策を守ってください。
