How it works

One bridge. Three simple steps.

SmartHub sits between your phone or controller and the USB target — a thin physical execution layer, not another cloud agent.

01

Plug in

Connect SmartHub to the target over USB. It enumerates as keyboard, mouse and joystick HID (manufacturer visualbuild.me).

02

Join SoftAP

Connect to the visualbuild.local hotspot (initial password build.me) and open the hosted web UI on your phone or tablet.

03

Control

Drive touch, mouse, keyboard, DualSense, remotes and recordings — without installing software on the target machine.

Product highlights

Built for SoftAP stability first.

SmartHub prioritizes a usable local hotspot under real phone and controller load — then layers remotes, gamepads and recording on top.

AP

SoftAP web remote

Pico-hosted HTTP / WebSocket UI. Join the hotspot, authenticate once, and keep control local — no cloud round-trip for input.

DS

DualSense & controllers

Pair DualSense and supported pads, map sticks and buttons, and bridge them to USB HID joystick / mouse / keyboard on the target.

HID

USB HID bridge

Keyboard, mouse and joystick output for machines that cannot (or must not) install a control agent — legacy PCs, kiosks, locked images.

REC

Recording & BOOTSEL

Capture actions in the browser, export/import libraries, store a script on the Pico, and trigger playback from configurable BOOTSEL actions.

TV

Apple TV / Google-style remotes, touch gestures, and iPad + Apple Pencil input paths designed for real tablet use.

SEC

Access password

One device access password for SoftAP and home-network HTTP / WebSocket. Change it in Settings; factory reset restores the initial password.

FAQ

Before you buy

Does the target need ASB or SmartHub software installed?

No for basic USB HID bridge use. The target only needs to accept a standard keyboard / mouse / joystick. ASB on visualbuild.me is the optional upstream automation plane.

Is SmartHub the same as Automation Skill Builder?

No. SmartHub is the Pico SoftAP / DualSense hardware bridge (visualbuild.local). Automation Skill Builder is the desktop/local AI automation product on visualbuild.me. They can work together; they are not the same product.

How do I connect the first time?

Plug SmartHub into USB, join the visualbuild.local SoftAP (initial password build.me), open the hosted page, and sign in with the same access password. You can change the password later in Settings.

Can firmware be updated from Android?

Yes — ASB Burn is the standalone Android / desktop companion for firmware install and recovery.

Does BLE stay on all the time?

BLE command reception is opt-in and default-off. SoftAP stability takes priority over always-on radio features.
